# Syself 目标工作树：行动聚焦路径设计

日期：2026-09-03  
状态：已实施，待用户体验确认

## 1. 目标

将当前的「月目标卡片 + 周目标列表」改造成可沿纵轴阅读的目标路径：

```text
唯一主目标
    ↓
当前月目标 ── 未来月目标（淡化、收起）
    ↓
当前周目标 ── 未来周目标（淡化、收起）
    ↓
今日行动组：关键行动 + 至少两项支撑行动
```

它不是一棵要求用户同时阅读所有分支的思维导图，而是一条从长期方向流向今天的行动路径。用户首先看见今天的三项任务；月、周目标负责说明这些任务为什么存在。

## 2. 视觉与层级

- 路径从上向下生长，中心细连接线只承担层级关系，不使用箭头、荧光描边或每张卡片左侧色条。
- 卡片尺寸随粒度缩小：主目标最大，月目标次之，周目标再次，单项日任务最小。今日行动组可使用容器承载三张日任务卡，但不应比周目标视觉更重。
- 色彩限定为暖白背景、深松绿文字/当前态、低饱和鼠尾草绿完成态、浅雾灰未来态、低饱和琥珀待采纳态。颜色永远搭配状态文字和图标使用。
- 当前路径使用清晰边界和适度阴影；非当前未来节点使用低对比填充与虚线边框，避免与当前行动竞争。
- 关键行动可以拥有更高对比度与稍大版面，但与支撑任务共用同一套圆角、边框和色彩体系；不使用左侧强调条。
- 保留低刺激、偏工具而非游戏化奖励的调性。任务闯关界面的启发仅用于「当前关卡突出、未来关卡可见但默认收起、路径可回看」，不引入经验值、等级或连胜叙事。

## 3. 当前与未来状态

### 当前路径

当前分支中，包含今天的日期或处于 `active` 状态的月、周节点默认为展开。用户能直接看到：标题、完成标准、状态、编辑/完成/暂停操作，以及该周对应的当日行动。

### 未来节点

开始日期晚于今天的月、周目标作为未来节点处理：

- 初始仅显示节点标题、时间范围、状态与「点击展开」提示。
- 采用浅色、低对比、虚线边界；不展示内部周目标或日任务。
- 点击节点本身（或「展开」按钮）后才显示其子层和节点操作；再次点击可收起。
- 建议状态仍保留「待采纳」文字与操作，不能仅依赖淡色区分。

完成、暂停、已延展和历史分支不会被混同为未来节点；它们保留状态标签，并可通过历史/详情入口查阅。

## 4. 今日行动组

树的末端增加「今日行动 · AI 已安排 N 项」容器，默认适配 AI 每日输出的三项任务：

1. 一项关键行动，展示完成标准、预计时间、所属当前周目标，并提供完成入口。
2. 至少两项支撑行动，以同等可读性展示标题、最低行动或完成标准、预计时间与状态。
3. 若任务多于三项，先显示三项并以「查看其余 N 项」进入今日行动页面；若少于三项，明确显示尚可安排的数量而非伪造空任务。

任务仍是实际持久化的 `task` 数据，按 `work_node_id` 关联到周目标；目标工作树不创建一套重复的日任务状态。

## 5. 交互与编辑

- 「生成 AI 建议」「新建月目标」保留在页面标题区；月目标和周目标沿节点提供编辑、完成、暂停与创建下级目标操作。
- 用户手动创建和编辑的字段、校验与持久化逻辑保持不变，继续使用现有内联编辑器。
- 从今日任务卡可完成任务，并链接/定位到所属周、月路径；从周节点可进入「今日行动」查看完整任务列表。
- 展开或收起仅改变浏览状态，不改变目标与任务数据。动画仅限高度/透明度的短过渡，并遵守减少动效偏好。

## 6. 数据与 API 变更

`GET /api/goal-work-tree?goalId=` 扩展为返回当前分支节点以及关联任务摘要。每个任务摘要至少包含：

| 字段 | 用途 |
| --- | --- |
| `id`、`title`、`status` | 渲染与完成操作 |
| `work_node_id` | 归属周目标 |
| `day_date` | 判断是否为今日行动 |
| `success_criteria`、`minimum_action` | 关键行动及支撑行动说明 |
| `estimated_minutes` | 任务容量提示 |

页面以本地今天日期筛选 `planned` 或 `in_progress` 状态的任务，将其放入当前激活周节点下的今日行动组。没有归属周目标的今日任务放入「未归属今日行动」小组，并给出归属提示，不能悄悄丢失。

`TreeNode` 类型补充 `start_date`、`end_date` 和必要的任务摘要类型；不修改既有节点创建、编辑、采纳、完成、暂停接口的含义。

## 7. 可访问性与响应式

- 树使用语义化层级和列表关系，而不是仅靠绘制线条传达父子关系；所有展开控件为可聚焦按钮，提供 `aria-expanded`。
- 状态始终以文字、图标/边框样式与颜色共同表达；正文和背景满足可读对比度。
- 小屏幕改为单列纵向路径，连接线保持居中或左侧一致，不产生横向拖动。今日三任务改为单列卡片。
- 键盘焦点、保存失败、任务为空、未创建目标与加载态沿用工作区既有反馈模式。

## 8. 验收标准

1. 用户能在同一纵向路径中看到主目标 → 月 → 周 → 今日行动的归属关系。
2. 当前月、周与今天任务默认展开；未来月、周默认淡化且折叠，点击后展开。
3. 今日行动区域能清晰容纳并展示至少三项任务，其中关键行动优先但不造成视觉失衡。
4. 所有月、周目标既有的创建、编辑、采纳、完成与暂停操作仍可用且刷新后保留。
5. 今日任务的完成状态更新后，树和今日行动页面的状态一致。
6. 窄屏、键盘和减少动效偏好下，路径仍然可理解、可操作。

## 9. 不做的事

- 不增加生产依赖或图形图库；用现有 React 与 CSS 完成路径结构。
- 不把未来节点的淡化解释为禁用：用户仍可主动展开、编辑或采纳。
- 不改变唯一主目标、当前规划分支和不可变决策路径的模型。
- 不将预览中的示例任务写入用户的真实目标数据。
