# 工作台标题文案调整设计

## 目标

将五个持久工作台页面的主标题压缩至八个汉字以内，提升首屏整齐度，并让页面意图一眼可辨。

## 范围

仅调整主标题文案，不改变页面结构、路由、数据读取、交互或次级说明文字。

| 页面 | 新主标题 |
| --- | --- |
| 仪表盘 | 今天先做关键事 |
| 决策路径 | 每一步都有来处 |
| 目标工作树 | 远大目标近处落地 |
| 今日行动 | 此刻只做一件事 |
| 每日复盘 | 为明天留出余地 |

## 验收标准

- 五个主标题均不超过八个汉字。
- 各页面的主标题使用一致的简洁、行动导向语气。
- 现有页面功能和测试保持正常。
