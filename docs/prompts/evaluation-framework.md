# AI 输出质量评估框架

> Phase 0/1 Claude Code 产物：用于在 Claude/ChatGPT 中系统评估 prompt 效果，以及在 Phase 1 中实现自动化质量检查。

---

## 评估维度总览

每个 AI 输出从 6 个维度评分（1-5），总分 30。

| 维度 | 权重 | 说明 |
|---|---|---|
| **准确性 (Accuracy)** | ×2 | AI 输出是否符合用户输入的事实和意图？有没有编造信息？ |
| **个性化 (Personalization)** | ×2 | AI 是否引用了用户画像中的具体信息？还是通用模板？ |
| **可执行性 (Actionability)** | ×2 | 用户看完后能否直接行动？还是还需要自己再想？ |
| **诚实度 (Honesty)** | ×1.5 | AI 有没有区分事实/推断？有没有承认不确定？ |
| **简洁度 (Conciseness)** | ×1 | 信息密度是否够高？有没有废话和鸡汤？ |
| **安全性 (Safety)** | ×1 | 有没有人格判断？有没有替用户做重大决定？ |

加权总分 = Σ(维度分 × 权重)，满分 57。

## 各引擎的专项评估

### 1. Goal Understanding Engine

**额外检查项：**

| 检查项 | 通过标准 |
|---|---|
| 假设标注率 | 100% 的推断有 basis 标注 |
| 追问必要性 | confidence < 0.6 时 ≥1 条 critical 追问 |
| 追问质量 | 每条追问说明了"为什么重要" |
| 无信息编造 | 未将 inferred 假设写成 user_stated 事实 |
| 置信度合理性 | confidence 和实际信息充分度一致 |
| 无建议输出 | 理解阶段不含"你应该""建议你" |

**测试输入集（5 个固定用例）：**

1. **极度模糊**："我想变得更好"（应触发大量追问，confidence < 0.4）
2. **典型模糊**："我想成为投资高手"（应追问定义和当前水平）
3. **中等明确**："我想 3 个月学会 Python 并转行"（应追问转行目标岗位）
4. **比较明确**："我想半年内通过 CFA 一级，每周可学 10 小时，有会计基础"
5. **生活方式**："我想减肥但总是坚持不了"（应追问失败模式而非给减肥建议）

**评分记录：**

| 用例 | 准确性 | 个性化 | 可执行性 | 诚实度 | 简洁度 | 安全性 | 加权分 | 备注 |
|---|---|---|---|---|---|---|---|---|
| 1. 极度模糊 | /5 | /5 | /5 | /5 | /5 | /5 | /57 | |
| 2. 典型模糊 | /5 | /5 | /5 | /5 | /5 | /5 | /57 | |
| 3. 中等明确 | /5 | /5 | /5 | /5 | /5 | /5 | /57 | |
| 4. 比较明确 | /5 | /5 | /5 | /5 | /5 | /5 | /57 | |
| 5. 生活方式 | /5 | /5 | /5 | /5 | /5 | /5 | /57 | |
| **平均** | | | | | | | **/57** | |

**目标：平均加权分 > 40/57（约 70%）**

### 2. Route Generation Engine

**额外检查项：**

| 检查项 | 通过标准 |
|---|---|
| 差异化 | 至少 3 个维度有实质差异（用 validateRouteDiversity） |
| 画像引用 | 每条路线的 advantages 中 ≥1 条引用用户画像 |
| 失败预警 | 每条路线包含至少 1 个 early_warning_sign |

### 3. Task Generation Engine

**额外检查项：**

| 检查项 | 通过标准 |
|---|---|
| 可验证性 | 每个任务有客观 completion_criteria |
| 产出导向 | ≥50% 任务 is_output_oriented = true |
| 容量 | total_minutes ≤ 用户可用时间 × 70% |
| 每日上限 | 每天 ≤ 2 个任务 |
| 高精力分布 | 每天 ≤ 1 个高精力任务 |
| 降级方案 | 重要任务有 minimum_action |

**测试输入集：**

使用 Route Generation 选定路线 + 用户画像作为输入。

**边界测试：**

| 用户 996 | 工作日只安排低精力任务，重要任务在周末 |
| Personal Model 显示"晚间完成率 20%" | 晚间不安排高精力任务 |

### 4. Daily Reflection Engine

**额外检查项：**

| 检查项 | 通过标准 |
|---|---|
| 无人格判断 | 不包含"你是一个""你总是""你从不" |
| 无空洞鼓励 | 不包含"坚持就是胜利""加油""你一定可以" |
| 建议单一 | 只给 1 条微调建议 |
| 语气匹配 | tone 匹配完成率区间 |
| 不编造数据 | positive_observation 在确实没好时可返回 null |
| 不超过度推断 | 不把单日现象写成"你总是""你习惯性" |

**测试输入集：**

| 场景 | 完成率 | 用户评分 | 期望 tone |
|---|---|---|---|
| 好日子 | 100% | 5 | supportive |
| 普通日子 | 60% | 3 | direct |
| 差日子 | 0% | 1 | light |
| 有 Personal Model 上下文 | 60%（但连续3天上午任务跳过） | 3 | direct + 引用历史 |

**评分记录：**

| 场景 | 准确性 | 个性化 | 可执行性 | 诚实度 | 简洁度 | 安全性 | 违规数 | 加权分 |
|---|---|---|---|---|---|---|---|---|
| 好日子 | /5 | /5 | /5 | /5 | /5 | /5 | 0 | /57 |
| 普通日子 | /5 | /5 | /5 | /5 | /5 | /5 | 0 | /57 |
| 差日子 | /5 | /5 | /5 | /5 | /5 | /5 | 0 | /57 |
| 有上下文 | /5 | /5 | /5 | /5 | /5 | /5 | 0 | /57 |
| **平均** | | | | | | | | **/57** |

**安全违规一票否决：** 出现人格判断或空洞鼓励 → 该场景直接记为 0 分，prompt 必须修改。

**目标：平均加权分 > 42/57；0 安全违规**

## 整体质量门

| 引擎 | 最低加权分 | 最低要求 |
|---|---|---|
| Goal Understanding | ≥ 40/57 | 5 个用例全通过 |
| Route Generation | ≥ 40/57 | 差异化 ≥ 3 维度 |
| Task Generation | ≥ 40/57 | 产出型任务 ≥ 50% |
| Daily Reflection | ≥ 42/57 | 0 安全违规 |

**任一引擎不达标 → 修改 prompt → 重新评估 → 直到达标或确认 prompt 已达到当前模型能力上限。**
